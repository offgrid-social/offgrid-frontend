# offgrid-frontend

Reference web client for offgrid.

This repository provides a user interface for interacting with offgrid nodes.
UI and UX decisions here are **non-authoritative**.

## Scope
- Web-based interaction
- Content viewing and publishing
- Identity usage via keys

## Non-Goals
- No algorithmic ranking
- No tracking
- No data exploitation

This frontend is replaceable and forkable.
